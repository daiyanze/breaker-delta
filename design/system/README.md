# Breaker Delta · Tide Paper

Breaker Delta（中文名：浪尖）的界面设计系统，方向代号「潮报 Tide Paper」：页面充满报纸的样式，但不拘泥于报纸的形式，有专色、有留白，并且版面由数据自己排。

设计稿在画布「Breaker Delta · UI 设计」里：https://claude.ai/artifact/JgaVWBaLnLKMfiibiMgrgB 。本文提到的画板编号都指那张画布。

## 一句话原则

1. **骨架固定，形式各异。** 每个页面都是左窄栏放栏目名、右宽栏放内容；右栏里每一段用一种报纸自带的栏目形式（潮汐表、启事、票根、剪报、分类广告）。
2. **版面由数据排。** 标题字号等于浪高，墨色等于新旧。同一个页面每小时长得不一样。
3. **专色有固定含义。** `red` 只表示「今天新成的浪」，`sun` 只表示「被选中」或「请看这里」，`blue` 是水和链接。
4. **每段一处图或动效，都很轻。** 开启「减少动态效果」时全部静止。
5. **首页不是榜单。** 完整排名压进索引；往下每一段回答一个不同的问题。

## 文字

- 界面的权威语言是英文。中文、日文是各自独立的页面，用 hreflang 互相声明，同一个页面里不混排语言，也不提供页内语言切换。
- 句首大写，不用全大写，不用标题式大写。
- 栏目名是报纸栏目或一个问题：Tide table、Fading notices、Classifieds、Were we right?、The clippings。
- 按钮写清楚点了会发生什么：Read all 214 echoes、Open the track record。
- 数字不加修饰：196、+63%、Down 18% in 24 hours。浪高不带单位。
- 讣告式的玩笑口吻只用在「退潮启事」里（A wave since Nov 13. Peaked at 188. Survived by 22 echoes.），其他地方保持平实。
- 没有数据时直说，并指出下一步：No verdicts yet. The first is due on Nov 26.
- 回波的标题永远是来源的原文，模型不改写。模型写的内容（摘要）下方有一行说明。

## 颜色

所有颜色都在 `tokens.json` 里，有浅色和深色两套值。使用规则：

| token | 用在哪 | 不要用在哪 |
|---|---|---|
| `paper` | 页面底色 | |
| `ink` | 正文、标题、粗线、按钮描边 | |
| `ink-2` | 次要文字、正在退的浪 | `sun` 上、`solid` 上 |
| `hair` | 细线、点线、硬边投影 | 文字 |
| `red` | 新成的浪、头条浪高、印章、日历页眉、更正 | 普通强调、错误提示以外的装饰 |
| `blue` | 链接、走势线、回波薄板 | 大面积底色 |
| `sky` | 海浪远层、薄板浅色层 | 文字 |
| `tint` | 图表面积、对照栏底色 | 整段通栏底色 |
| `sun` | 浪数标签、选中的报纸、栏目名高亮、光束 | 多个元素同时使用抢焦点 |
| `on-sun` | `sun` 上的文字 | |
| `solid` | 海浪前层、岩石、台面、页尾底栏 | 文字 |

深色模式跟随系统设置，并记住用户的手动选择。深色下 `red` 和 `blue` 调亮，`sun` 不变，页尾变成夜海：`solid` 比底色更深，海浪和岩石成为剪影。

不使用渐变、模糊投影和半透明叠色（灯塔光束的 55% 黄色是唯一例外）。

## 字体

两个家族，都来自 Google Fonts：

- **Fraunces**（`display`）：报头、标题、所有浪高数字、斜体栏目名。
- **Instrument Sans**（`body`）：正文、导航、按钮、说明。

数字统一用等宽数字（tabular-nums）。最小字号 13px。具体样式见 Typography。

### 中文和日文页面

Fraunces 没有汉字和假名，所以中日文页面给每个家族配一个后备：

- `display`：Fraunces（拉丁字母和所有数字）加 Noto Serif SC 或 Noto Serif JP，标题字重 900，英文用斜体的地方改用字重 500。
- `body`：Instrument Sans 加 Noto Sans SC 或 Noto Sans JP，16px、行高 1.75。
- 头条字号 = 34 + 浪高 ÷ 200 × 34；第二层 20 + 浪高 ÷ 200 × 16；第三层 16 + 浪高 ÷ 200 × 9。
- 标题行高 1.16 到 1.3，字距 0，严格断行，标点不出现在行首。
- 回波标题保持来源原文不翻译；字标保持 Breaker Delta，中文页在旁边加「浪尖」，日文页加「波頭」并在上方注读音なみがしら。
- 每种语言的页面只加载自己的两个 Noto 家族。见画板 35。

## 版式

- 内容区最大 `content`（1280px），左右留白 `space-6`（手机 20px）。
- 每一段是一个 band：上下留白 `space-8`（手机 `space-7`），顶部一条 `rule-thin`。
- band 内左栏最宽 `rail`（340px），放斜体栏目名、一句说明、一个链接，也可以放一幅小插画；滚动时左栏吸顶。右栏放内容。
- 头版区例外：内容在左，索引在右。
- 手机上左栏变成段落标题，叠在内容上方；小插画缩小后放在标题右侧。
- 任何地方都不出现横向滚动条。放不下的东西用叠放（报纸）、换行（信息带）或收进下拉（导航、语言）解决。

## 数据驱动的规则

| 规则 | 公式或条件 |
|---|---|
| 标题字号 | 见组件 Headline |
| 回波薄板层数 | 浪高 ÷ 200 × 12，最少 3 |
| 启事波纹振幅 | 浪高 ÷ 200 × 16，最小 2 |
| 报纸缩略图横杠 | 那一版前三名的浪高 ÷ 2，单位是百分比 |
| 潮汐表海面 | 每条新成的浪在成形钟点贡献一个钟形隆起，叠加后按最高点等比缩放 |
| 海况 | 今天新成 ≥4 为 choppy，2 到 3 为 moderate，否则 calm |

## 图标

- 界面图标是线性图标，线宽约 1.8px，18px 画板，颜色跟随文字。
- 来源图标见组件 SourceTile：实现时用各来源网站自己的 favicon，通用图标作兜底。
- 产品图标已定稿，见组件 Icon 和画板 25：白红白灯塔加 Δ，左侧一个浪头。Night 是主图标，Day 和 One ink 为辅；报头字标左侧放 One ink 圆章。

## 已经定下来的事

- 中文名是「浪尖」，日文名是「波頭」（なみがしら）。
- 访问统计支持 Umami、Plausible、Google Analytics 三种。只有 Google Analytics 设 cookie，打开它时站点底部出现 cookie 选择条（画板 48）；不放广告。
- 隐私政策的保存期限：退订后 30 天内删除邮箱，未确认的地址 48 小时后删除，服务器日志保留 14 天。
- 话题合并后沿用较早的成形日期和较早的 14 天判断。
- 邮件用 React Email 编写；投递做成可替换的接口，默认 Cloudflare Email Sending，也可以填任意 SMTP，不填则关闭邮件功能。
- 版次邮件由数据自动生成；人工只能通过四个模板写邮件，只填文字。
- 发送时间按站点时区，所有订阅者同一时刻收到；连续 3 次退信后自动停发。
- 管理端可以手动添加订阅者，默认发确认邮件；直接计为已确认时要勾选声明并留下记录。
- 分享图在第一次被请求时生成并存下来，每个话题每种语言横竖各一张。
- 公开站点每种语言一个页面，用 hreflang 互相声明；管理端在页面内切换语言。
- 报摊一排显示最近 12 次运行（默认每小时一次），更早的收进 Earlier 一摞和 Back issues 抽屉；只提供最近 7 天。「一版」只是一次运行的展示叫法，不另存快照。
- 管理端的登录方式是可选项，不绑定 Cloudflare Access。
- 组件全部按本设计系统自建，不用第三方组件库（原定的 WunderUI 已取消）。
- 不设单独的落地页，头版就是落地页，解释放在 About 页。
- 变化有七种：成浪、上升、摘要更新、更正、撤回、结论、已平息，Changes 页七种标签都有。
- 已确认的结论不原地修改；改判是新增一条记录，原结论保留并划掉，印章为 Revised。
- 分享图由流水线绘制并存储，站点只读。
- 邮件默认 08:00 发送，时区默认 Asia/Tokyo，两项都能在管理端 Mail 页签里改。
- 设计稿、token 和文案表在仓库的 `design/` 目录里有一份，供开发时对照。
