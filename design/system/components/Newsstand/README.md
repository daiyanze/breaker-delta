首页的报摊：用来在最近的各版之间切换。「一版」是一次运行的展示叫法，数据读自每次运行的浪高记录，不另存快照。运行间隔是设置，默认每小时一次，下面的数字都按默认值写；间隔改了，小报仍然一次运行一份。整行通栏，不出现滚动条。画板 01、02。

- **招牌和遮阳棚**：招牌写当前选中那一版的标题；遮阳棚是一整幅带描边的条纹图形。
- **当天的小报**：一排最多 12 份（最近 12 次运行，默认即最近 12 个小时），最新的在右。每份是组件 EditionPaper，三根横杠是那一版前三名的浪高。放不下时从最旧的开始隐藏，小报之间不重叠。
- **Earlier 一摞**：一排最左侧的一摞报纸，点开下方的 Back issues 抽屉；抽屉展开和收起有过渡动效。
- **Back issues 抽屉**：上面一行日期选项，下面是那一天每次运行的小报（默认 24 份），与当天的小报是同一种画法；没跑成的那一次留空位。只提供最近 7 天。
- **下一版**：最右侧一捆未拆的报纸，写下一次扫描的时间和倒计时；手机上是一份虚线框的幽灵报纸。
- **Back to the latest edition**：只在选中的不是最新版时出现，放在这一行里，不另占一行。
- **猫**：黑猫、黄眼睛（见组件 Mascot），趴在报亭顶上，腿收起。点一下：半睁眼、摇尾巴。双击：站起来露出腿，跳到报亭后面躲起来，5 秒后跳回顶上再趴下。猫在屋顶线以下的部分被裁掉，躲起来时完全看不见。开启「减少动态效果」时猫不动。
- 手机上小报缩到 56×84，抽屉每行 5 份。
