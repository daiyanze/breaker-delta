- 印章：3px 框、圆角 `radius-stamp`。六种状态，靠样式区分而不只靠颜色：

| 状态 | 文案 | 样式 |
|---|---|---|
| 待到期 | Due Nov 26 | 2px `ink` 虚线框，不旋转 |
| 复核中 | Under review | 2px `ink-2` 框和字，不旋转 |
| 命中 | Hit | `ink` 实底、`paper` 字，旋转 -4° |
| 部分命中 | Partial | `blue` 框和字，旋转 -4° |
| 未命中 | Miss | `red` 框和字，旋转 -4° |
| 无法判定 | Undecided | `ink-2` 虚线框和字，旋转 -4° |
