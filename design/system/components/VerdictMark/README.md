战绩页「Every wave so far」里的小圆标记，每个登记过的浪一个，按时间排列。

| 状态 | 形状 |
|---|---|
| 命中 | `ink` 实心圆 |
| 部分命中 | `ink` 描边，左半边实心 |
| 未命中 | `red` 描边，中间一个叉 |
| 无法判定 | `ink-2` 虚线圈，中心一个小点 |
| 复核中 | `sun` 实心、`ink` 描边 |
| 还没到期 | `hair` 空心圈 |

- 直径 26px，间隔 8px，桌面每行 14 个，手机每行 10 个。
- 六种状态都能靠形状分辨，不依赖颜色。下方必须带图例。
- 没有任何结论时全部是空心圈，同时页面顶部不显示命中率。
- 命中率 = （命中 + 部分命中 × 0.5）÷ 已确认条数，无法判定的不计入。
