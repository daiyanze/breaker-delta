没有内容或出了问题时放在内容区的一段话。画板 17 到 21。

| 情况 | 出现在哪 | 写法 |
|---|---|---|
| 空（刚装好，还没扫描过） | 首页、各列表页 | 说清楚现在没有什么、什么时候会有、现在能做什么。No waves yet. The first scan runs at 15:00. |
| 安静（只有一两个浪） | 首页 | 版面照常排，空出来的栏目写一句实话：A quiet sea. 2 waves up, nothing new since 09:00. |
| 局部出错 | 某一段取不到数据 | 只有那一段换成这段话，其他段照常显示。写发生了什么和怎么办，不道歉，不写「出错了」这种空话。 |
| 整页出错 | 服务不可用 | 报头保留，内容区一段话加一个重试按钮。 |
| 404 | 找不到页面 | 救生圈插画，一句话，两个去处：首页和搜索。 |

- 标题用 `display` 斜体 38px；说明 17px `ink-2`；最多一个按钮。
- 每种情况最多一幅插画，且不重复使用其他页面已经用过的插画。
- 画板 20 是出错状态的对照表，不是读者会到达的页面。
