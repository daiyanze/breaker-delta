邮件的统一版式。三封版次邮件（确认订阅、晨间版、每周版）和四个手写模板都用它。画板 29、50。

- 600px 单栏，只有浅色。从上到下：One ink 圆章加字标、波浪线、可选的一个标签、内容、深色页尾（为什么收到这封信、退订链接）。
- 用 React Email 编写，版次邮件和手写模板共用同一套组件；模板是仓库里的文件，构建时打包，自建的人加一个文件后重新部署即可；邮件由流水线渲染和发送。
- 四个手写模板：
  - **通知**：黄色标签，标题、正文、可选按钮。用于故障和停机。
  - **更正**：红色标签，标题下面是一个带红色竖线的块，上面是划掉的原话，下面是加粗的正确说法；作者不能省掉原话。
  - **公告**：蓝色标签，标题、正文、可选按钮。用于新功能和变更。
  - **信件**：没有标签和标题块，称呼、正文、落款。
- 写邮件界面里各模板的填写项见画板 49（通知）和画板 52（更正、公告、信件）。更正模板的「We wrote」和「It should say」必填。
- 待核查的摘要不进任何邮件。
- 手写的邮件只填文字：正文只支持加粗、链接、列表，不能改字体、颜色和版式。
- 每封最多一个吉祥物，放在报头右侧或落款旁；Breaker 负责送信，Delta 只出现在信件模板的落款旁。
- 字体加载不了时回退到 Georgia 和系统字体；关掉图片后内容完整；没有动效。
