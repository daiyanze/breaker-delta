One ink 圆章、字标加导航，下面一条流动的波浪线。所有页面使用同一个报头。

- 圆章在字标左侧，高度是字标字号的 0.84 倍，与字标垂直居中，间距 0.14em。圆章和字标是同一个回首页的链接。见组件 Icon。
- 字标用 `masthead` 样式，靠左；导航靠右，与字标底部对齐。当前页的导航项加粗，底部一条 4px `red`。
- 波浪线是 3.5px `ink` 描边的正弦线，周期 60px，30 秒向左流动 240px。线上有一艘小帆船以每秒 16px 向右行驶，每 2.5 秒越过一个浪，上下 ±3.5px、俯仰 ±5°。
- 手机上：圆章 34px（最简画法），字标 38px 单行，导航收进 "Sections" 下拉按钮。
- 开启「减少动态效果」时波浪和船都静止。
- 管理端（the desk）不用这个报头，用自己的深色顶栏。
