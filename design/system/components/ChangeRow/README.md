Changes 页里的一行：一个种类标签、发生了什么、时间。按每次运行分组（默认每小时一次）。画板 11、12。

| 标签 | 含义 | 样式 |
|---|---|---|
| New wave | 一个新的浪成形 | `red` 底、`paper` 字 |
| Rising fast | 浪高明显上升（幅度取自设置） | `ink` 描边 |
| Summary updated | 摘要重写 | `ink-2` 描边和文字 |
| Correction | 人工更正 | `red` 描边和文字 |
| Withdrawn | 摘要被撤回 | `red` 双线描边和文字 |
| Verdict in | 14 天判断有了结论 | `ink` 底、`paper` 字 |
| Went flat | 浪退到阈值以下 | `ink-2` 虚线描边 |

- 一行里标题是链接，指向话题页；右侧是时间。行与行之间一条 `hair` 细线。
- 标签文字固定为上表七种，不加图标，与流水线记录的七种变化一一对应。
- 七种标签靠填充、描边线型（实线、双线、虚线）和文字区分，不只靠颜色。
- 筛选项相应为：Everything、New waves、Rising、Summaries、Corrections、Withdrawn、Verdicts、Went flat。
