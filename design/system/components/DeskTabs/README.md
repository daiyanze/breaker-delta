管理端（the desk）的页签和设置行。管理端功能清楚即可，不做插画和动效。画板 24。

- 六个页签：Settings、Verdicts、Topics、Corrections、Scans、Mail。选中的一项 `ink` 底 `paper` 字，页签下一条 4px `ink`。
- 设置行：左边名称和一句说明，右边控件；同一组里每一行内容区高度一致（44px），控件右对齐。
- **语言**：管理端在页面内切换英文、中文、日文，记住选择；这一点与公开站点（每种语言一个页面）不同。全部 102 条文案三种语言都要有。
- **登录方式**是一个可选项，不写死：仅本机、密码、Cloudflare Access、登录代理四选一。界面上的说明文字随选项变化。
- 会改动公开内容的操作（下结论、改标题、发更正）在提交前显示将要公开的样子。
- **Mail 页签**（画板 49）六块：下一版（预览、试发、扣住）；写邮件（选模板、填文字、右侧实时预览）；投递设置（Cloudflare Email Sending、SMTP、关闭三选一）；最近的发送；订阅者（计数、查一个人、导出、删除）；手动加人（发确认邮件，或勾选声明后直接计为已确认）。
- 登录页和首次设置见画板 45、46；这三块画板都能在页面内切换英文、中文、日文。
