产品图标：一座白、红、白三段的灯塔，红段上有大写 Δ，灯室两扇窗，左右各一束光；灯塔左侧一个不卷的浪头朝它探过来。画板 25。

- **Night**（主图标）：`ink` 浅色值作底。用于应用图标、favicon、社交头像、分享卡片。
- **Day**：`tint` 作底，塔身加一圈细墨线。用于浅色背景上需要彩色图标的地方。
- **One ink**：圆形单色章，只用 `ink` 和 `paper`，随主题换色。用于报头字标左侧、印章、单色印刷。
- 颜色全部来自 token：塔身 `paper` 和 `red` 的浅色值，光束、灯室 `sun`，近浪 `blue`，远浪 `sky`，底带 `solid`。图标里的颜色不随深浅主题变化，只有 One ink 例外。
- 三档细节：100px 以上完整画法；48 到 99px 去掉栏杆、线条加粗；47px 以下再去掉窗框和 Δ。
- 四周留出图标宽度八分之一的空白；不拉伸、不加投影、不改颜色。
