两个吉祥物，名字取自产品名的两半：黑猫叫 **Delta**，白色海鸥叫 **Breaker**。文案里提到名字时总是带上身份：Delta the cat、Breaker the gull。画板 33。

- **黑猫**：`solid` 平涂，没有描边，眼睛用 `sun`，鼻子和耳朵内侧是粉色。九个姿势：打盹、半醒（眯眼、大瞳孔）、站立、走路（尾巴竖直）、伸懒腰、正面坐着、背面坐着、蜷成一团、从边缘探头。只画猫真实会做的动作。住在报摊，出现在报亭顶上，以及报摊或管理端「休息中」的场合。
- **海鸟**：白色身体、`ink` 描边、`sky` 翅膀、`sun` 喙和腿，脸颊一点粉色。九个姿势：远景（两段弧线，页尾天空和漂流瓶上方已在用）、飞行、叼着信飞、站立、浮在水面、正面、背面、站在木桩上、张嘴叫。住在海上，负责在海和读者之间送东西：邮件、订阅成功、退订页。
- 每幅插画最多一个吉祥物。
- 颜色用三个专用 token：`cat`（浅色下墨色，深色下提亮成石板蓝，这样在夜色背景上看得见）、`gull-line` 和 `gull-wing`（两种主题下相同）。海鸥的白是纯白 `#FFFFFF`，粉色是 `#FF7A5C`，都只用在吉祥物身上。海鸥的腿是黄色加墨色描边，在纸色背景上才看得清。
- 不穿衣服、不说话、身上不带文字。开启「减少动态效果」时不动。
- 猫的瞳孔一律是圆的；各姿势的瞳距与头宽的比例一致。爪子、后腿和嘴用 `ink-2` 细线勾出。海鸟的喙尖有一个红点，翅尖和尾尖是墨色。
- 最终素材建议在矢量工具里画或请插画师画，每个姿势导出一个 SVG 文件；这里的图形是设定草图。
