来源图标的小方块，放在来源名前面。

- 尺寸 34px（分类广告里 30px），1.5px 描边，圆角 `radius-tile`。
- 实底（`ink` 底、`paper` 图标）：故事从这里开始的来源。描边（`paper` 底、`ink` 图标）：后来跟进的来源。这一对替代了早期稿里的实心点和空心点；信息带里仍用小圆点表示数量。
- 图标内容：实现时显示该来源网站自己的 favicon。取不到，或来源是一个组（媒体组、通讯组）时，用按类型区分的通用图标：对话气泡是论坛，人像是关键账号，报纸是媒体或博客，放大镜是新闻检索，信封是通讯，代码括号是代码托管。
- 图标必须带文字来源名，不单独出现。
