# 0001 Clean-slate rewrite

Date: 2026-11-18. Status: accepted.

## Decision

2.0 is a new project. No source code and no data from the previous version is
carried over. Old URLs are not preserved. The public data repository is
emptied and reused. The track record starts from zero.

## Why

The previous site has no users, so there is nothing to migrate for. Starting
clean removes the need to match old behavior.

## Consequence

The first review results exist no earlier than 14 days after the official
instance starts running. That sets the earliest launch date.
