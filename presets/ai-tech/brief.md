# 行业简报 · AI 科技（ai-tech preset）

给分级 agent 的行业口径。扫描与分级的通用机制（共振、浪高、复盘）在
引擎与 Skill 里，与行业无关；这一页只写 AI 科技这个行业特有的判断。

## 读者与用途

读者主要是内容创作者与产品开发者：他们要比同行更早拿到可写、可做的
选题，并且每条都要能点回原始出处。所以入选标准偏向「有具体物」：
新模型、新产品、新仓库、新政策原文、真实的资本动作；泛泛的行业评论
和二手转述降权。

## 什么算这个行业的大事

- 头部实验室与厂商的模型发布、版本更新、定价与开放权重变化
- Agent 与应用层的新产品、新协议、开发工具的实质更新
- 开源生态的爆发性仓库与基础设施变化
- 监管与政策原文（法案、禁令、出口管制）及其对厂商的直接影响
- 资本动作：融资、收购、IPO、财报里的 AI 业务信号
- 安全事件：漏洞、泄露、攻击手法公开

## 分层直觉

- L1 源头层（官方博客、GitHub、Hacker News、Hugging Face、Product
  Hunt 等）：新面孔先在这里出现，单源先记回波。
- L2 发酵层（Reddit、Google News、应用榜单）：同一事件多家跟进 =
  开始扩散，是升「关注」的主要证据。
- L3 只核对（Google Trends）：只看曲线形状，永不作为发现来源。

## 分类口径

分类体系在同目录 config.yaml 的 `categories` 段：安全 / 政策与监管 /
开源 / 商业与资本 / Agent 与应用 / AI 模型，兜底行业动态。分类由
发布器按关键词规则自动完成，agent 不手工改分类；觉得分类不对时，
改的是规则，不是单条结果。

## 语气与边界

- 标题与摘要用主语言（zh）撰写，并按 Skill 要求同时给出 en/ja。
- 不收纯营销稿、无原文出处的搬运、与 AI 科技无关的泛科技新闻。
- 扫描频度由使用者自定，本 preset 不规定时间表。
