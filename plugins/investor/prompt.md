# 投资研判 · 分级注入口径

对每个进入必看/关注的话题，多做一层投资视角的判断，按 schema.yaml
产出结构化字段，存入条目的 plugins.investor。

口径：
- 给的是**研判视角与核查清单**：影响方向、受影响标的、时间尺度、
  一句话逻辑、一句话风险与反证。
- 标的只写与话题有直接业务关联的上市公司（代码 + 名称）；关联弱
  就留空，不要硬凑。
- 方向拿不准就写「不明」，逻辑里说明还缺什么信息。

红线（不可违反）：
- **不给具体买卖点位、目标价、仓位比例或「买入/卖出」指令。**
- 不预测股价涨跌幅；不把传闻写成事实，未证实的消息在 logic 里
  标明「未证实」。
- 面板的免责声明由系统强制渲染，你不需要、也不能改写它。
